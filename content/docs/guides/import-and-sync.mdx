# Import and sync

Most teams evaluating a CRM layer need to answer one operational question quickly: how does data move in and out?

## Typical sources

- CSV exports from legacy CRMs
- warehouse snapshots
- product events
- marketing and sales systems

## Why code-first helps

If the schema is explicit, imports and sync jobs can target a known contract instead of reverse-engineering whatever exists in an admin UI.

## Practical concerns

- external IDs
- deduplication rules
- validation behavior
- retry and observability strategy
