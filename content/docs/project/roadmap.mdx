# Roadmap

Roadmap pages are for the parts of OboeCRM that are important, but not stable enough to present as fixed public contract.

## Why this page exists

It keeps the main docs honest.

Use the main path for:

- current model and evaluation flow
- public-facing concepts
- stable architectural intent

Use roadmap pages for:

- planned features
- moving implementation details
- open design questions

## Good roadmap candidates

- CLI expansion
- deeper migration workflows
- advanced admin customization
- richer integration surfaces
