# FAQ

## Is OboeCRM for developers or CRM admins first?

Developers first. The project is framed around schema, APIs, and infrastructure ownership.

## Is the admin UI the source of truth?

No. The admin layer is meant to follow the model, not replace it.

## Why focus so much on self-hosting?

Because control, auditability, and deployment ownership are central to the product's positioning.

## Why are some pages more conceptual than exhaustive?

Because the project is early. The docs favor honest evaluation and public-contract clarity over fake completeness.

## Where should unstable or future work go?

Into [Roadmap](/docs/project/roadmap), not the main reference path.
