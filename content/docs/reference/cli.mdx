# CLI

The CLI should exist to reduce repetitive project setup and operational friction, not to become a second control plane.

## Purpose

A good CLI for OboeCRM would help with:

- project scaffolding
- local development tasks
- environment-aware operational commands
- migration-related workflows

## Design constraint

The CLI should complement the config model, not hide it. If a task can only be understood through a wizard and not from versioned files, the workflow becomes harder to review and maintain.
