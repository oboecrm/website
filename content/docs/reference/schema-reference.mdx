# Schema reference

This reference describes the core pieces the schema is built from.

## Purpose

Use the schema to model CRM entities in code and to establish the contract other surfaces should follow.

## Minimal example

```ts
schema: {
  Account: {
    fields: {
      name: { type: "text", required: true },
      domain: { type: "text", unique: true },
    },
  },
  Deal: {
    fields: {
      value: { type: "currency" },
    },
    relations: {
      account: "Account",
    },
  },
}
```

## Main concepts

### Objects

Objects represent business entities such as accounts, deals, contacts, or custom records.

### Fields

Fields capture values, validation requirements, uniqueness, and other constraints relevant to that object.

### Relations

Relations link entities in ways the API and admin layers can understand consistently.
