# GraphQL API

This page explains the role of GraphQL in OboeCRM.

## Purpose

GraphQL is the flexible query surface for applications and internal tools that need to shape responses around UI or workflow requirements without breaking away from the same core schema.

## Minimal shape

GraphQL should reflect the schema's objects and relations in a way that stays conceptually aligned with the REST surface and the admin layer.

## Good fit

- custom React or Next.js interfaces
- embedded operator workflows
- queries that span related records
- internal tools that need composition over fixed endpoints
