# OboeCRM Website

This repository powers the official website for **OboeCRM**, an open-source, code-first CRM. It hosts marketing pages, landing content, and product messaging.

## ✨ Tech stack

- [Next.js](https://nextjs.org/) (App Router)
- TypeScript
- [Tailwind CSS](https://tailwindcss.com/) v4
- [shadcn/ui](https://ui.shadcn.com/) (built on [Radix UI](https://www.radix-ui.com/))
- [Biome](https://biomejs.dev/) (lint / format)

## 🚀 Running the project locally

1. Clone the repository
2. Install dependencies

   ```bash
   npm install
   ```

3. Start the development server

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Other scripts

| Command          | Description              |
| ---------------- | ------------------------ |
| `npm run build`  | Production build         |
| `npm run start`  | Start production server  |
| `npm run lint`   | Run Biome checks         |
| `npm run format` | Format with Biome        |

If you use `pnpm` or `yarn`, substitute it for `npm` in the commands above.
